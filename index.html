¡Consigue tu enlace web!

Sigue estos pasos rápidos en GitHub para tener un enlace que puedas compartir por WhatsApp con las familias del IES:

  1. Regístrate gratis en github.com.
  2. Haz clic en "New" para crear un repositorio. Ponle el nombre que quieras (ej: matricula).
  3. Márcalo como Public y pulsa "Create repository".
  4. En tu nuevo repositorio, pulsa "uploading an existing file" y arrastra este archivo guardado con el nombre exacto index.html. Luego pulsa "Commit changes".
  5. Entra en la pestaña Settings (Configuración) de ese repositorio.
  6. Busca la sección Pages en el menú lateral izquierdo.
  7. En "Branch", cambia None por main o master y pulsa Save.
¡Listo! En un minuto, GitHub te dará un enlace arriba como:
https://tu-usuario.github.io/matricula/
